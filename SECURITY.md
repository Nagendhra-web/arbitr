# Security policy

Arbitr is safety software. We take reports seriously and fix them first.

## Reporting a vulnerability

Please do not open a public issue. Report privately through the "Report a
vulnerability" button on the repository Security tab (GitHub private
vulnerability reporting). Include steps to reproduce, the version and the
impact you see. You will get an acknowledgement within 3 working days and a
plan within 10.

## Supported versions

| Version | Supported |
|---|---|
| 0.x (pre-release) | latest commit on `main` only |

This table is updated at each release.
